# Content Guide

Контент добавляется декларативно и не должен разрастаться в `switch` внутри сцен.

## Способность

1. Добавьте типизированный config в `src/content/abilities/`.
2. Опишите id, владельца, cooldown, стоимость, targeting и фазовые modifiers.
3. Реализуйте/переиспользуйте pure core rule.
4. Сопоставьте доменные события с Phaser presentation.
5. Добавьте unit-тест правила и smoke для видимого результата.

## Враг

1. Добавьте config в `src/content/enemies/` с уникальным id и читаемым telegraph.
2. Соберите поведение из существующих policy/commands; новое правило начинается в core.
3. Добавьте визуальный adapter/entity без расчёта damage в сцене.
4. Проверьте counterplay и приоритет слабого кота тестами.

## Уровень

1. Добавьте config в `src/content/levels/` с arena, encounters, checkpoints и objectives.
2. Ссылайтесь на enemy/ability ids, не создавайте классы врагов внутри level scene.
3. Новая механика сначала безопасно обучается, затем используется в бою и комбинации.
4. Добавьте lazy loader, cleanup-проверку и e2e основной цели.
5. Зарегистрируйте уникальные monster ids уровня в `monster-rosters.ts`; обычные враги не должны
   повторяться между уровнями без сюжетного обоснования.

Точные config-схемы появятся вместе с первыми двумя реальными потребителями на этапах 1–2 — это
избегает преждевременной абстракции.
