# Canonical ability icons

The seven PNG files in `abilities/` follow `docs/ECLIPSE_PAWS_SCENARIO.md`:

- Lumus: Stunning Cry, Light Beam and Light Circle;
- Nox: Shadow Dash, Shadow Needles and Shadow Veil;
- shared: Eclipse.

Each icon is an independent 1254×1254 RGBA master with a transparent background. Runtime UI
integration should create optimized 128 px and 256 px derivatives while retaining these masters.

`items/` starts the Garden of First Dawn set with a golden seed, dew leaf, memory echo and Memory
Gate quest symbol. They use the same independent RGBA-master policy.
