## Именование: расхождение с планом §7

План предписывает `category_character_action_variant_frame.ext` (snake_case, например
`chr_lumus_run_day_01.png`). Реальные файлы art-агента используют
`<character>-<action>[-<variant>]-v<N>.png` (kebab-case с версионным суффиксом, например
`lumus-run-contact-v1.png`, `dream-garden-first-dawn-v1.jpg`). Соглашение **внутренне
последовательно** и содержит стабильный semantic ID (имя файла без версии), но не совпадает
буквально с конвенцией плана. Решение зафиксировать здесь, а не менять: переименовывать 395 уже
доставленных файлов ради формата — небезопасная механическая правка без функциональной пользы
(риск сломать пути импорта во всех уже написанных adapter-файлах). Рекомендация: принять
фактическое соглашение art-агента как действующее (обновить пример в плане §7 отдельным решением
пользователя, если нужно формально), а не расходовать задачу на переименование.
