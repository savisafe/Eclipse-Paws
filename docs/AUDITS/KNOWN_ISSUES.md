- При планировании следующих задач сверяться с колонкой «Task ID» — часть проблем уже имеет
  назначенную задачу.

  §5. Каждое исправление либо уже привязано к существующему `ARC-NNN`, либо требует нового,
  отдельно согласованного task ID.
